# 💧 Aqua — трекер привычек

Личный десктоп-трекер: вода + напоминания, счётчик калорий, задачи (to-do), привычки, календарь. Красивый тёмный/светлый интерфейс, плавные анимации, шрифты Manrope + Inter. Все данные хранятся **локально** на твоём компьютере и никуда не отправляются.

---

## Как запустить

### Способ 1 — просто (рекомендую, ничего ставить не надо)
Дважды кликни **`Запуск Aqua.bat`** (с чёрным окном консоли — закрыть консоль = выключить трекер)
или **`Aqua (без консоли).vbs`** (запуск скрыто, как приложение; выключить — через Диспетчер задач → `node.exe`).
Откроется отдельное окно приложения (Edge/Chrome в режиме приложения — без вкладок, с иконкой, как настоящая программа).
Нужен только **Node.js** (есть) и Edge или Chrome (есть оба).

Либо из терминала: `npm start`

### Установить как настоящее приложение (замена .exe)
В открытом окне Aqua нажми меню Edge/Chrome (⋯) → **«Установить Aqua»** (или значок «Установить» в адресной строке при обычном запуске).
Появится ярлык в меню Пуск и на рабочем столе со своей иконкой, окно без браузерной обвязки, работает офлайн. Это PWA — то же самое приложение ставится и на телефон (см. ниже).

> Про **.exe через Electron**: на этой машине npm рвёт большие загрузки (`ECONNRESET`), поэтому собрать exe-бандл Electron сейчас не выходит. Установка PWA даёт тот же результат (иконка, своё окно, автозапуск) без 100-МБ загрузки — и заодно работает на телефоне.

### Способ 2 — полноценное окно Electron (опционально)
Даёт нативное окно + иконку в системном трее + напоминания о воде, которые работают, даже когда окно свёрнуто в трей (закрытие окна прячет его в трей, а не выключает).
Сначала поставь Electron, потом запусти:
```bash
npm install --save-dev electron
npm run electron
```
Electron качает ~100 МБ; при нестабильной сети установка может обрываться (`ECONNRESET`) — тогда просто пользуйся Способом 1, он полностью самодостаточен.

## Что внутри

- **💧 Вода** — большая анимированная бутылка, быстрые кнопки +200/+300/+500/+750 мл и своё количество. Цель считается автоматически (~35 мл на кг веса). Напоминания с настраиваемым интервалом и «тихими часами».
- **🍎 Калории** — цель по калориям и БЖУ считается по формуле Миффлина-Сан Жеора из твоего профиля. Добавление еды:
  - **Поиск** и **Штрихкод** — бесплатная база [Open Food Facts](https://world.openfoodfacts.org) (без ключей и без нейросетей).
  - **Вручную** — вписать калории/БЖУ.
  - **Фото (AI)** — *опционально*. Оценка калорий по фото требует зрительной модели. Работает на **твоём** ключе Anthropic (Claude) — вставляется в настройках вкладки и хранится только на этом ПК. Без ключа не нужен — хватает поиска/штрихкода.
- **✅ Задачи** — to-do с приоритетами, сроками и фильтрами.
- **🔥 Привычки** — свои привычки с недельной сеткой и сериями (streak).
- **📅 Календарь** — месяц с отметками (вода/калории/задачи), клик по дню — детали.
- **⚙️ Профиль** — рост, вес, возраст, пол, активность, цель. Экспорт/импорт всех данных в JSON (бэкап) и полный сброс.

---

## Про калории по фото
Честно: точное определение калорий по фотографии **невозможно без зрительной ИИ-модели**. Чтобы не платить за это постоянно, сделано так:
- по умолчанию — бесплатный поиск и штрихкоды (Open Food Facts), нейросеть не нужна;
- фото-режим включается по желанию и работает на твоём ключе Claude — платишь только когда сам им пользуешься.

## Заметки
- Данные хранятся в браузерном хранилище для адреса `http://127.0.0.1:8899`. Запускай одним способом, чтобы история не «раздваивалась». Для бэкапа — **Профиль → Экспорт**.
- Файлы проекта: `index.html`, `styles.css`, `app.js` (интерфейс и логика), `server.js` (локальный запуск + прокси к API), `main.js` + `preload.js` (обвязка Electron), `assets/` (иконки).
