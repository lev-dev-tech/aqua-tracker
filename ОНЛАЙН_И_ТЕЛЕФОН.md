# 📱 Aqua на телефоне + синхронизация + пуши

План (всё бесплатно, без VPS и без App Store):
**один код → GitHub Pages (https) → ставится на iPhone и ПК → Firebase = аккаунт, синхронизация, пуши.**

Тебе нужно сделать **два бесплатных проекта** (GitHub + Firebase) и прислать мне их данные — дальше я всё дописываю в код и тестирую.

---

## Шаг A. Выложить приложение в интернет (GitHub Pages)

1. Заведи бесплатный аккаунт на https://github.com (если нет).
2. Создай репозиторий: кнопка **New** → имя, напр. `aqua-tracker` → **Public** (для бесплатного Pages) → **Create**.
3. Залей файлы проекта. В папке проекта в терминале:
   ```bash
   cd "C:\1 КОДИНГ\1 ПРОЕКТЫ\ТРЕКЕР ПРИВЫЧЕК"
   git init
   git add .
   git commit -m "Aqua tracker"
   git branch -M main
   git remote add origin https://github.com/ТВОЙ_ЛОГИН/aqua-tracker.git
   git push -u origin main
   ```
   (при первом push GitHub попросит войти — через браузер).
4. Включи Pages: репозиторий → **Settings** → **Pages** → Source: **Deploy from a branch** → Branch: **main**, папка **/(root)** → **Save**.
5. Через ~1 минуту адрес будет: `https://ТВОЙ_ЛОГИН.github.io/aqua-tracker/`

### Поставить на iPhone
Открой этот адрес в **Safari** → кнопка «Поделиться» → **На экран «Домой»**. Появится иконка-приложение. Уже работает: вода, калории (встроенная база + штрихкод), задачи, привычки, календарь. Данные пока хранятся на самом телефоне.

> ⚠️ iPhone: пуш-уведомления включатся только у приложения, добавленного **на экран «Домой»** (iOS 16.4+). Из Safari-вкладки пуши не приходят — это ограничение Apple.

## Шаг B. Firebase (аккаунт + синхронизация + пуши)

1. Зайди на https://console.firebase.google.com (вход по Google-аккаунту).
2. **Add project** → имя `aqua` → отключи Google Analytics (не нужен) → создать. Тариф **Spark (бесплатный)** — денег не просит.
3. Внутри проекта нажми иконку **`</>` (Web)** → зарегистрируй приложение (nickname `aqua-web`) → **скопируй блок `firebaseConfig`** (там apiKey, projectId и т.д.).
4. Слева **Build → Authentication → Get started → Sign-in method →** включи **Email/Password** (и, если хочешь, **Google**).
5. **Build → Firestore Database → Create database →** регион ближе к тебе → **Start in production mode** → включить.
6. **⚙️ Project settings → Cloud Messaging →** в разделе **Web Push certificates** нажми **Generate key pair** → скопируй **ключ (VAPID)**.

## Шаг C. Пришли мне

Скинь в чат:
1. Блок **`firebaseConfig`** (из шага B3).
2. **VAPID-ключ** (из шага B6).
3. Адрес твоего сайта на **GitHub Pages** (из шага A5).

После этого я допишу в приложение: вход по аккаунту, синхронизацию всех данных ПК↔iPhone в реальном времени, регистрацию пуш-токена и **расписание напоминаний о воде через бесплатный планировщик (GitHub Actions)** — чтобы «пей воду» приходило даже когда приложение закрыто.

> `firebaseConfig` и VAPID — это **клиентские** ключи, их не стыдно светить (они и так уходят в браузер). Секретный ключ (service account) для планировщика мы положим отдельно в GitHub Secrets — я подскажу как, его никому показывать не надо.
